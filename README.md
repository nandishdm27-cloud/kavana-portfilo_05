# AI Portfolio Architect

RTF Prompt for a Professional Student Portfolio

Role: Act as a world-class portfolio designer, personal branding strategist, and UX writer.

Task: Create a modern, premium portfolio for a 1st-year B.Tech student in Artificial Intelligence & Machine Learning. The portfolio should present me as a professional, ambitious engineering student seeking internships, hackathons, research opportunities, and leadership roles. Include sections for Hero, About Me, Skills, Education, Projects, Certifications, Achievements, Experience, and Contact with compelling, recruiter-friendly content.

Format: Deliver a complete portfolio with clean section-wise copy, a luxury black-and-white aesthetic, concise professional writing, LinkedIn-ready language, and responsive website layout suggestions.
